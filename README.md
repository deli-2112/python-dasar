## Cara Menjalankan

1. Pastikan Python 3.13 sudah terpasang.
2. Masuk ke folder kode:
   ```bash
   cd python-dasar
   ```
3. Jalankan file yang diinginkan:
   ```bash
   python main.py
   ```
